# FlashLearn

Mobilní aplikace pro efektivní učení pomocí kartiček (flashcards). Vyvinuto pro platformu iOS s využitím frameworku React Native a Expo. Veškerá data jsou ukládána lokálně v zařízení, aplikace funguje 100% offline a nevyžaduje registraci.

## Technologický stack

| Komponenta | Technologie |
| :--- | :--- |
| Framework | React Native (Expo) |
| Jazyk | TypeScript |
| Úložiště | AsyncStorage |
| Notifikace | expo-notifications |

## Lokální spuštění projektu

Pro spuštění projektu na macOS v simulátoru iOS nebo přes Expo Go zadejte do terminálu následující příkazy:

```bash
cd ~/FlashLearn
npm install
npx expo start
